# Card ERP Phase 2 & 3 功能概覽

**文件版本**: 1.0.0
**最後更新**: 2026-01-25
**狀態**: 📋 規劃中（待 Phase 1 完成後啟動）

---

## 📍 產品演進策略

```
Phase 1 (MVP) → Phase 2 (會員與社交) → Phase 3 (規模化與生態系)
   6-9 週          4-6 週                  6-8 週
```

### 核心原則

- ✅ **基於 Phase 1 實戰經驗調整**：不盲目執行，根據用戶反饋優化
- ✅ **漸進式增強**：每個 Phase 都是可獨立上線的完整版本
- ✅ **技術債務控制**：適時重構，避免累積技術債
- ✅ **數據驅動決策**：基於實際數據調整功能優先級

## 🎯 Phase 2: 會員與社交增強

**目標**: 從基礎交易平台升級為社群驅動的卡片交易生態
**預計時程**: Phase 1 完成後 4-6 週
**核心價值**: 提升用戶黏性、增加互動、建立社群

---

### 2.1 會員系統升級 ⭐⭐⭐⭐⭐

#### 功能清單

**2.1.1 OAuth 2.0 社交登入**

- Google OAuth 登入
- LINE Login 整合（台灣主流）
- Facebook Login
- 帳號綁定與解綁
- 第三方帳號合併邏輯

**2.1.2 會員等級系統**

- 會員等級定義（銅、銀、金、鑽石）
- 升級條件：消費金額、交易次數、評價分數
- 等級權益：折扣比例、優先購買、專屬活動
- 等級顯示與徽章系統

**2.1.3 點數系統**

- 消費回饋點數（可設定回饋比例）
- 點數抵現功能
- 點數過期機制
- 點數交易紀錄
- 簽到送點數（每日簽到）

**2.1.4 優惠券系統**

- 優惠券類型：折扣券、滿額券、免運券
- 優惠券發放：後台手動、自動發放、活動獎勵
- 優惠券使用條件：最低消費、商品類別、使用期限
- 優惠券核銷與記錄

**2.1.5 會員中心增強**

- 個人資料編輯（頭像上傳）
- 訂單歷史查詢（進階篩選）
- 收藏與追蹤管理
- 點數與優惠券管理
- 會員等級展示

**技術需求**

- OAuth 2.0 libraries (Passport.js / NextAuth.js)
- Redis 存 session 與 token
- Prisma schema 擴充：User、MemberLevel、Point、Coupon

**預估時程**: 2 週

---

### 2.2 社交與互動功能 ⭐⭐⭐⭐⭐

#### 功能清單

**2.2.1 商品評價與評論**

- 五星評分系統
- 文字評論（支援圖片上傳）
- 評論點讚與回覆
- 賣家回應評論
- 惡意評論檢舉與審核

**2.2.2 願望清單（Wishlist）**

- 商品收藏功能
- 降價通知（當收藏商品降價時通知）
- 願望清單分享（生成分享連結）
- 收藏數統計展示

**2.2.3 商品追蹤與提醒**

- 追蹤特定賣家
- 追蹤特定系列（如 Pokemon 25週年系列）
- 新品上架通知
- 競標結束前提醒

**2.2.4 用戶互動**

- 用戶關注功能（Follow）
- 活動動態牆（用戶購買、評論動態）
- 私訊系統（買賣雙方溝通）

**技術需求**

- Prisma schema: Review、Wishlist、Follow、Message
- WebSocket 擴充（即時通知）
- 圖片審核機制（Content Moderation）

**預估時程**: 2 週

---

### 2.3 搜尋與推薦系統 ⭐⭐⭐⭐

#### 功能清單

**2.3.1 進階搜尋**

- 全文搜尋（商品名稱、描述）
- 多條件篩選：
  - 價格區間
  - 鑑定分數範圍
  - 賣家評分
  - 上架時間
  - 商品狀態
- 搜尋歷史記錄
- 熱門搜尋關鍵字

**2.3.2 推薦系統**

- 基於瀏覽歷史的推薦
- 基於購買歷史的推薦
- 相似商品推薦（同系列、同等級）
- 熱銷商品排行榜
- 新品推薦

**2.3.3 智能分類**

- 自動標籤生成
- 商品分類優化
- 系列自動識別

**技術需求**

- Elasticsearch / Algolia（全文搜尋引擎）
- 推薦演算法（Collaborative Filtering 或簡單的規則引擎）
- Redis 緩存熱門數據

**預估時程**: 1.5 週

### 2.4 通知系統 ⭐⭐⭐⭐

#### 功能清單

**2.4.1 Email 通知**

- 訂單確認信
- 付款成功通知
- 出貨通知（含物流追蹤）
- 競標結果通知
- 促銷活動通知

**2.4.2 站內通知**

- 即時通知中心（導航欄顯示未讀數）
- 通知分類：訂單、系統、活動、社交
- 通知已讀/未讀管理
- 通知偏好設定

**2.4.3 推播通知（選配）**

- Web Push Notification
- 行動裝置推播（若有 App）

**技術需求**

- SendGrid / AWS SES (Email Service)
- WebSocket（即時通知）
- Service Worker (Web Push)
- Prisma schema: Notification

**預估時程**: 1 週

## 🚀 Phase 3: 規模化與生態系

**目標**: 打造開放式卡片交易生態系統，支援大規模用戶與國際化
**預計時程**: Phase 2 完成後 6-8 週
**核心價值**: 規模化、國際化、平台化

---

### 3.1 賣家平台 ⭐⭐⭐⭐⭐

#### 功能清單

**3.1.1 賣家入駐系統**

- 賣家申請與審核
- 賣家資料認證（身份證、營業登記）
- 店鋪設定（店名、Logo、簡介）
- 賣家等級制度

**3.1.2 賣家自助上架**

- 商品批次上傳（Excel / CSV）
- 商品管理後台（專屬賣家介面）
- 庫存管理
- 價格調整工具

**3.1.3 賣家營運工具**

- 銷售數據分析儀表板
- 訂單管理（出貨、退貨）
- 客戶管理（對話紀錄）
- 促銷活動設定

**3.1.4 賣家結算系統**

- 自動分潤計算
- 對帳單生成
- 提款申請與審核
- 稅務憑證管理

**技術需求**

- 獨立的賣家後台（Seller Portal）
- 複雜的權限管理系統
- 財務結算引擎
- Prisma schema: SellerApplication、Settlement、Withdrawal

**預估時程**: 3 週
